Lecture 1: Introduction to Recommender Systems

Comprehensive summary of foundational concepts, real-world case studies (Netflix Prize), data architectures (MovieLens 10M), and critical practical bottlenecks like the Cold Start Problem.

1. What is a Recommender System?

Systems designed to predict user ratings or implicit preferences for items. They form an integral part of modern digital business models:

  • Amazon: Generates ~35% of total revenue via recommendation modules.
  • Netflix: ~75% of content watched originates directly from recommendations.
  • Other Ecosystems: Google Search results, Facebook Timeline, Spotify Daily Mixes.

2. The Netflix Prize (2006–2009)

A $1 Million competition to improve Netflix's movie rating prediction accuracy (RMSE) by 10%.

Winner: BellKor's Pragmatic Chaos (2009) with a 10.06% improvement.

First Progress Prize: Korbell team achieved 8.43% improvement after 2,000+ engineering hours combining 107 algorithms.

3. "More Than Just an Algorithm"

Why Netflix didn't fully implement the winning algorithm in production:

  • Engineering Complexity & Scaling: The offline model was built for 100M static ratings, while Netflix scaled to 5B+ dynamic interactions.
  • Holistic Evaluation: Rating prediction accuracy is only one component. Real systems must optimize for Context, Title Popularity, Novelty, Diversity, Evidence, and Freshness.

4. MovieLens 10M Benchmark

Created by GroupLens (University of Minnesota, Twin Cities - Harper & Konstan).

10,000,054 Ratings
95,580 Applied Tags
10,681 Movies
71,567 Users

5. Data Schema (`::` Separator)

MovieLens 10M uses standard `.dat` plain-text files delimited by double colons (`::`):

ratings.dat: UserID::MovieID::Rating::Timestamp

movies.dat: MovieID::Title::Genres

tags.dat: UserID::MovieID::Tag::Timestamp

6. The Cold Start Problem

Occurs when the system lacks sufficient historical data to compute standard similarity metrics:

New User Cold Start:

No historical ratings or past preferences available to draw upon.

New Item Cold Start:

Newly introduced movie/product has zero interaction history or community feedback.

Python Pandas Data Loading Snippet

How to load the `.dat` files into Pandas DataFrames as specified in Slide 11: 

import pandas as pd

# 1. Load ratings file
ratings_df = pd.read_csv('ratings.dat', sep='::', 
                         names=['UserID', 'MovieID', 'Rating', 'Timestamp'], 
                         engine='python')

# 2. Load movies file
movies_df = pd.read_csv('movies.dat', sep='::', 
                        names=['MovieID', 'Title', 'Genres'], 
                        engine='python')

# 3. Check stats & sparsity
n_users = ratings_df['UserID'].nunique()
n_movies = ratings_df['MovieID'].nunique()
n_ratings = len(ratings_df)

sparsity = 1.0 - (n_ratings / (n_users * n_movies))
print(f"Sparsity: {sparsity * 100:.2f}%")
