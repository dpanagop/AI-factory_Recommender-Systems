Lecture 3: Collaborative Filtering & Item-Based Recommendation

Comprehensive summary of collaborative filtering principles, vector mapping (embeddings), cosine similarity calculations, rating matrices, and recommendation computation steps.

1. Collaborative Filtering Definition

A method of making automatic predictions (filtering) about a user's interests by utilizing preferences or taste information collected from many users (collaborating).

Core Idea: People helping each other discover great movies/items based on shared behavioral patterns.

2. Item-Based Approach

Define a notion of closeness or similarity between movies. Propose to a user movies similar to the ones they already prefer.

  • Map movies to vectors (embeddings) based on user ratings across the dataset.
  • Compute mathematical similarity scores between item vector pairs.

3. Cosine Similarity

Given two vectors \(x = (x_1, \ldots, x_n)\) and \(y = (y_1, \ldots, y_n)\), their cosine similarity is defined as:

$$\text{Sim}(x, y) = \frac{x \cdot y}{\|x\| \|y\|} = \frac{\sum_{i=1}^n x_i y_i}{\sqrt{\sum_{i=1}^n x_i^2} \sqrt{\sum_{i=1}^n y_i^2}}$$

4. Mapping to Vectors (Embeddings)

How do we map movies to vectors?

Load the .dat files in Python (using Pandas), construct the user-item rating matrix where each movie is represented as a vector across users, and implement item-based recommendation methods.

5. Similarity Matrix Processing

Handling similarity matrices in code:

  • Diagonal Zeroing: We set to zero the diagonal entries of the cosine similarity matrix so a movie doesn't recommend itself.
  • Concrete Calculation: e.g., Cosine similarity between Movie 1 and Movie 3 evaluates to \(\approx 0.98058\).

6. Recommendation Computation

How to score and recommend items:

To recommend movies to a user (e.g., User 1), we multiply the ratings given by the user to each movie with the corresponding column in the similarity matrix, sum the weighted scores, and rank the resulting predictions.

Python Cosine Similarity & Recommendation Snippet

How to compute item similarity and generate predictions in Python (scikit-learn / pandas): 

from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

# 1. Compute cosine similarity matrix between item vectors
similarity_matrix = cosine_similarity(rating_matrix.T)

# 2. Set diagonal entries to zero
np.fill_diagonal(similarity_matrix, 0)

# 3. Predict rating for user u on movie i
# Weighted sum of user's ratings by item similarity
predicted_rating = np.dot(user_ratings, similarity_matrix[:, movie_idx]) / np.sum(np.abs(similarity_matrix[:, movie_idx]))
