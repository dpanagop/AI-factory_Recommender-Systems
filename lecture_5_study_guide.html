Lecture 5: Scalable Recommenders with PySpark ALS & Neo4j

Comprehensive summary of large-scale distributed collaborative filtering using PySpark's Alternating Least Squares (ALS) matrix completion and graph-based recommendation using Neo4j and Cypher.

1. Apache PySpark Distributed Engine

Unified open-source analytics engine developed at UC Berkeley AMPLab for large-scale cluster data processing with implicit data parallelism and fault tolerance.

Why for Recommenders? Scales matrix calculations across thousands of worker nodes when user-item matrices exceed single-node RAM.

2. Alternating Least Squares (ALS)

Decomposes large rating matrix $R \approx U \cdot V^T$ into user factors $U \in \mathbb{R}^{m \times k}$ and item factors $V \in \mathbb{R}^{n \times k}$.

$$\min_{U,V} \sum_{(u,i) \in R} (r_{ui} - \mathbf{u}_u^T \mathbf{v}_i)^2 + \lambda (\|\mathbf{u}_u\|^2 + \|\mathbf{v}_i\|^2)$$

Alternating optimization: Fix $V$ and solve convex quadratic form for $U$; then fix $U$ and solve for $V$.

3. PySpark ALS Parameters

Key API configurations in pyspark.ml.recommendation.ALS:

  • rank: Number of latent factor dimensions $k$ (e.g., 10–50).
  • regParam ($\lambda$): Regularization factor to prevent overfitting.
  • coldStartStrategy: Set to "drop" to avoid NaN predictions on unknown test items.

4. Neo4j Property Graph Model

Represents items and users as graph nodes connected by directional, property-rich relationships.

(u:User)-[r:RATED {Rating: 5}]->(m:Movie)
User attributes: Gender, Age, Occupation | Movie attributes: Title, Genres

5. Neo4j & Python GraphDataScience

Connects Python to Neo4j database using Bolt protocol (bolt://localhost:7687).

  • Node constraints: CREATE CONSTRAINT ... REQUIRE (n.id) IS NODE KEY
  • Batch processing using UNWIND $data AS row MERGE ...

6. Cypher Path Traversal

Finds similar movies by counting graph paths through common satisfied users:

MATCH (m1:Movie)-[r1]-(u:User)-[r2]-(m2:Movie)
WHERE m1.Title CONTAINS 'Toy Story'
  AND r1.Rating=5 AND r2.Rating=5
RETURN m2.Title, count(DISTINCT u) AS common_users
ORDER BY common_users DESC

Tool 2: Cypher Graph Query & Co-Rating Recommendation Tester

Test graph traversal recommendations on MovieLens data by finding movies co-rated highly by overlapping users. 

MATCH (m1:Movie)-[r1:RATED]->(u:User)-[r2:RATED]->(m2:Movie)
WHERE m1.Title CONTAINS 'Toy Story (1995)'
  AND m2.Title <> 'Toy Story (1995)'
  AND r1.Rating = 5 AND r2.Rating = 5
RETURN m2.Title, m2.Genres, count(DISTINCT u) AS common_users
ORDER BY common_users DESC
LIMIT 5
