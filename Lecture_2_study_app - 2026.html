Lecture 2: Matrix Factorization & Collaborative Filtering

In-depth exploration of Matrix Factorization, Singular Value Decomposition (SVD), Stochastic Gradient Descent (SGD) with L2 regularization, evaluation strategies, and latent factor interpretability.

1. System Evaluation & Train/Test Splitting

Proper offline validation is crucial before deploying recommendation models.

  • Temporal Split (Last-K): Uses timestamps so test set contains the user's most recent $k$ ratings, mimicking real-world future prediction.
  • Random User Split: Randomly partitions interactions (e.g., 80% train / 20% test) across known users.
  • Cold User Handling: Decisions must be made on whether test sets allow unseen users not present during training.

2. Matrix Factorization Concept

Decomposes the user-item interaction matrix $R_{n \times m}$ into lower-rank user preference matrix $P_{n \times k}$ and item weight matrix $W_{k \times m}$.

Predicted Rating:

$$\hat{r}_{ij} = \sum_{l=1}^{k} pr_{il} w_{lj} = \mathbf{p}_i^T \mathbf{w}_j$$

Where $k$ represents hidden/latent characteristics (e.g., action level, drama, pacing).

3. SVD Formulation

Linear algebra decomposition of matrix $A_{m \times n}$:

$$A = U \Sigma V^T$$
• $U$: $m \times m$ orthogonal matrix (Left singular vectors)
• $\Sigma$: $m \times n$ diagonal matrix (Singular values $\sigma_1 \ge \sigma_2 \dots$)
• $V^T$: $n \times n$ transpose orthogonal matrix (Right singular vectors)

4. Drawbacks of Standard SVD on Sparse Data

Why direct linear algebra SVD breaks down on real recommender matrices:

  • Sparsity & Imputation: Standard SVD requires a dense matrix. Imputing missing values with 0s or means introduces severe noise.
  • Overfitting to Imputed Data: The algorithm optimizes reconstruction of non-interactions rather than true underlying user preferences.

5. Regularized Stochastic Gradient Descent (SGD)

Minimizes error directly over observed ratings $\Omega$ with $L2$ regularization:

Error: $e_{ij} = r_{ij} - \mathbf{p}_i^T \mathbf{w}_j$

$\mathbf{p}_i \leftarrow \mathbf{p}_i + \gamma (e_{ij} \mathbf{w}_j - \lambda \mathbf{p}_i)$

$\mathbf{w}_j \leftarrow \mathbf{w}_j + \gamma (e_{ij} \mathbf{p}_i - \lambda \mathbf{w}_j)$

6. Latent Factor Interpretability

Uncovering the semantics of abstract mathematical dimensions:

Genre Averaging:

Average row vectors of $V^T$ for all movies in a genre to project genre profiles into latent factor space.

Clustering:

Apply K-Means clustering on $V^T$ combined with tags/genres to reveal hidden film archetypes.
